SNAPVERA OCR - OPTIONAL LOCAL ENGINE

Snapvera ne ukljucuje Tesseract OCR binary niti language modele.

Za portable OCR mozete smjestiti kompatibilnu Windows instalaciju Tesseracta u ovu mapu tako da postoji:

  SnapveraTools\\tesseract\\tesseract.exe
  SnapveraTools\\tesseract\\tessdata\\...

Alternativno Snapvera moze koristiti Tesseract instaliran u standardnoj Program Files lokaciji.

OCR se pokrece lokalno. Privremena slika se brise nakon prepoznavanja.
