Snapvera 1.0.0 Portable
Author / Publisher: Brendigo
Website: https://snapvera.com.hr/

Run Snapvera-Portable.exe (or the architecture-specific portable EXE).
Snapvera starts in the Windows system tray; normal startup does not require a main popup window.

Portable data is stored beside the executable in SnapveraData:
- settings
- history metadata
- diagnostic logs

Portable mode does not register Snapvera settings or Start with Windows in the registry.
OCR is optional and can use a local Tesseract installation.
