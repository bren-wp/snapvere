# Third-party notices — Snapvera 1.0.0

Snapvera source in this package is built with the Go toolchain and calls Windows system APIs.

## Tesseract OCR

Tesseract is **not bundled as an executable** in this Snapvera release. Snapvera can optionally detect and invoke a separately installed local Tesseract OCR engine. Users/distributors are responsible for complying with the license terms of the Tesseract package they install or redistribute.

## No copied competitor source

The Snapvera source tree in this release is a clean implementation. It does not bundle or copy Lightshot, ShareX, Flameshot, Greenshot, Clowd or Snapboard source code.
